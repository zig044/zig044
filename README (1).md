## 🚀 Featured Projects

### 🛣️ AI-Based Pothole Detection & Maintenance Prioritisation System

An AI-powered road damage detection system using a custom-trained **YOLO11** model. Built REST APIs with Python and FastAPI, integrated image uploads and report management, and designed a priority-scoring algorithm based on pothole severity, size, detection confidence, road type, and repeat occurrences.

| Layer | Technology |
|:--|:--|
| Computer vision | YOLO11 (Ultralytics) |
| Backend | Python, FastAPI |
| Database | PostgreSQL |
| Features | Image uploads, detection, reports, repair prioritisation |
